نمای کلی و شروع

Overview & Getting Started

Agent یک دستیار هوشمند است که از طریق تلگرام (ربات یا MTProto) با شما صحبت می‌کند و می‌تواند کارهایی روی کامپیوتر انجام دهد: فایل‌ها را مدیریت کند، برنامه‌ها و پنجره‌ها را کنترل کند، دستور اجرا کند، مرورگر را اداره کند، اسکرین‌شات بگیرد، یادآور بگذارد و حتی با دیدن صفحه، کارهای چندمرحله‌ای مستقل انجام دهد.

Agent is a smart assistant that chats with you via Telegram (Bot API or MTProto) and can do tasks on your computer: manage files, control apps and windows, run commands, run the browser, take screenshots, set reminders, and — by viewing the screen — perform independent multi-step tasks.

  • 🖥️
    برنامهٔ گرافیکی:GUI app: اجرا/توقف ایجنت از پنجره یا آیکون سینی + تنظیمات آسان.start/stop the agent from the window or tray icon + easy settings.
  • ✈️
    تلگرام:Telegram: همان ایجنت — دستورات، ابزارها و تاییدها اینجا.the same agent — commands, tools, and confirmations here.
  • 🌐
    پنل وب (اختیاری):Web panel (optional): کنترل از مرورگر روی همین کامپیوتر یا شبکهٔ خانه.control from a browser on this PC or home network.

اجرا: روی ویندوز با دابل‌کلیک `Agent.exe` (یا `python launcher.py`)، یا `python main.py` برای حالت فقط تلگرام. برای اولین بار باید توکن ربات (از BotFather) و آیدی عددی خودتان را وارد کنید.

نکته: ایجنت یک پردازش جداست؛ خرابی آن برنامهٔ گرافیکی یا ترای را نمی‌اندازد و تا ۵ بار در ۵ دقیقه خودکار دوباره بالا می‌آید.

راهنما را هر زمان باز کنید: در تلگرام `؟` بفرستید یا از منوی تنظیمات. پنل وب هم صفحهٔ راهنما دارد.
Reopen this guide anytime: send `?` in Telegram, or open it from the Settings menu. The web panel also has a help page.
💬 نسخهٔ بله هم هست: به‌جای تلگرام می‌توانید همین ایجنت را روی بله اجرا کنید — در تنظیمات «پیام‌رسان» را روی bale بگذارید و توکن ربات بله را بدهید (راهنمای کامل: BALE_README_FA.md).
💬 There is also a Bale version: you can run the same agent on Bale instead of Telegram — set “Messenger” to bale in Settings and enter your Bale bot token (full guide: BALE_README_FA.md).

سوالات متداول

FAQ & Troubleshooting

برنامه بالا نمی‌آید

App won't start

فقط یک نمونه اجرا می‌شود (موتث تک‌نمونه). اگر پنجره تکراری می‌بینید، نمونهٔ قبلی را از ترای ببندید (`توقف کامل و خروج`).

تنظیمات ذخیره نشد

Settings didn't save

فایل `settings.dat` فقط با DPAPI همین کاربر ویندوز باز می‌شود. اگر آن را جابجا کردید یا با کاربر دیگری باز کردید، خطا می‌دهد. پیام خطا معمولاً توضیح می‌دهد.

ایجنت وصل نمی‌شود

Agent won't connect

  • توکن و آیدی را بررسی کنید.
  • حالت اتصال (`mtproto` / `bot_api`) و پروکسی/رله را چک کنید.
  • لاگ را از منو `فایل` ← نمایش لاگ ببینید (توکن‌ها ماسک می‌شوند).

کلید API خطای 401/403 می‌دهد

API key gives 401/403

کلید از فاصله و کاراکتر نامرئی پاک می‌شود. اگر سرویس پایتون را می‌بندد، `AI_USER_AGENT` را تنظیم کنید. اگر آدرس API را `…/v1/chat/completions` نوشتید، خودکار به `…/v1` اصلاح می‌شود.

حافظه پر شده یا قدیمی است

Memory full or old

با `/forget yes` همه گفتگوها پاک می‌شوند. `KEEP_HISTORY=0` ذخیره را خاموش می‌کند.

تغییر مدل/کلید بدون ریستارت

Change model/key without restart

از تلگرام: `/model نام`، `/key کلید`، `/baseurl آدرس`، `/provider add/use/del`. فایل `providers.json` در `settings.dat` ذخیره نمی‌شود — کنار `.env` (یا پوشه داده) است؛ آن را به کسی ندهید.

ایجنت روی دیواره گیر کرد

Agent hung in a loop

از تلگرام `/stop` بفرستید. قفل «یک کار در هر زمان» و محدودیت ۳ بار تکراری هم جلوی حلقه را می‌گیرد.
